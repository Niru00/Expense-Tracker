# Expense Tracker

## About Project
Expense Tracker is a Python-based application
that helps users manage their income and expenses.

## Features
- Add Income
- Add Expenses
- View Transactions
- Calculate Balance
- Set Monthly Budget
- View Remaining Budget
- Search Transactions
- Generate Monthly Reports

## Technologies Used
- Python
- File Handling

## How to Run
1. Install Python.
2. Open the project in VS Code.
3. Open Terminal.
4. Run this command:

   python expense_tracker.py
